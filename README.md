# Honours Project 2025

This repository contains the Quarto Markdown (`.qmd`) files and functions used for simulating network topologies, performing community detection, and evaluating the performance of the detected communities. The results from these analyses are stored in various `.rds` files.

## Repository Contents

- `*.qmd` files: Quarto Markdown files used for simulation, community detection, and evaluation.  
- `*.rds` files: Stored results of simulations and analyses.  

## Project Overview

This project focuses on:

1. **Network Simulation**: Creating and analyzing various network topologies.  
2. **Community Detection**: Applying algorithms to identify communities within the networks.  
3. **Performance Evaluation**: Using custom functions to assess the quality of detected communities.
